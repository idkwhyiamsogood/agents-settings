# Личные правила Codex

При работе с документами прочитай `document-rules/README.md` относительно
каталога этого глобального AGENTS.md, затем только относящиеся к задаче модули.
Для других задач эти модули не загружай.

Применяй правила как личные значения по умолчанию с учётом инструкций более
высокого приоритета, явного запроса пользователя и правил проекта.
Не переносить содержание, стек или ограничения одного проекта в другой.
Не предполагать ОС, оболочку, домашний каталог, доступность программ и сервисов:
использовать сведения текущей среды и поддерживаемые интерфейсы приложения.
