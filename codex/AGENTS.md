# Личные правила Codex

## Работа с документами

При создании, редактировании, проверке или восстановлении документов любого
проекта сначала прочитай `~/.codex/document-rules/README.md`, затем перечисленные
там модули, относящиеся к задаче. Не загружай их для задач, не связанных
с документами. Если CODEX_HOME переопределён, используй каталог этих правил
рядом с данным глобальным AGENTS.md.

Применяй правила как личные значения по умолчанию с учётом инструкций более
высокого приоритета, явного запроса пользователя и применимых правил проекта.
Не переносить содержание, стек или ограничения одного проекта в другой.
