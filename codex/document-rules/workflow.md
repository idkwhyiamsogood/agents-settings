# Контекст и последовательность работы

- Перед правками определить актуальный файл, цель, адресата, формат результата,
  доступные образцы и связанные материалы. Искать имеющийся контекст до вопросов.
- Читать содержимое исходника, а не делать выводы только по имени файла.
- Образец использовать для структуры, оформления и нотации. Заменять чужую
  предметную область, авторов, роли, стек, показатели и выводы данными проекта.
- Сохранять идентификаторы требований, термины, единицы измерения, роли и ссылки.
  Сверять связанные документы, схемы, таблицы и формулы. Обоснованные изменения
  вносить согласованно, не перенумеровывать сущности молча.
- Различать требования, допущения, проектные решения и подтверждённые результаты.
  Не объявлять реализацию, испытания и соответствие стандартам доказанными
  без проверок. Не придумывать отсутствующие данные или источники.
- При больших изменениях собирать и сохранять документ по частям, включая
  готовые схемы по мере работы. Перед завершением проверять комплект целиком.
- Соблюдать запрошенный формат. Для текстового документа при отсутствии
  других указаний предпочитать редактируемый DOCX. Не прилагать PDF, если он
  не запрошен; временный PDF для проверки вёрстки допустим.
- Передавать понятную итоговую версию со ссылкой. Не выдавать промежуточные
  файлы за результат и не создавать дополнительные документы без необходимости.
