# Правила работы с документами

Область: текстовые документы, отчёты, проектные материалы и связанные с ними
схемы, таблицы и источники во всех проектах. Содержимое конкретного проекта
определяется его текущими материалами и заданием пользователя.

Читай только подходящие модули; Markdown-файлы ниже не подгружаются сами:

| Модуль | Когда читать |
| --- | --- |
| [workflow.md](workflow.md) | Всегда при работе с документом: контекст, согласованность и результат. |
| [preservation.md](preservation.md) | При изменении, удалении или восстановлении файлов. |
| [standards.md](standards.md) | Если есть нормативные требования, ГОСТы или формальные нотации. |
| [diagrams.md](diagrams.md) | При работе со схемами, диаграммами и иллюстрациями. |
| [formatting.md](formatting.md) | При оформлении, сборке и проверке вёрстки. |
| [sources.md](sources.md) | При составлении библиографии и проверке внешних сведений. |
| [tools.md](tools.md) | При выборе инструментов, skills, экспорте или автоматизации. |

Не считать этот набор установленным skill. Это тематические инструкции,
подключённые из глобального AGENTS.md. Не изменять настройки инструментов
или разрешения на выполнение команд ради применения этих инструкций.
