# Сохранность, изменения и восстановление

- Перед существенной перезаписью обеспечить откат: существующая версия Git
  или временная копия. Не создавать каталоги резервных копий в проекте
  автоматически, если пользователь их удалил или они не нужны для задачи.
- Сохранять структуру пакета, вложения, стили и связи документа, если их
  изменение не требуется. Точечные изменения предпочтительнее полной пересборки.
- Восстанавливая удалённый файл, сначала проверить текущие файлы, git status,
  историю нужного пути и доступные временные копии. Восстанавливать точный blob
  через `git show <commit>:<path>`, не откатывая весь рабочий каталог.
- Не использовать `git reset --hard` для восстановления отдельного документа.
  Не перезаписывать несвязанные изменения пользователя.
- Если точная копия не найдена, отличать реконструкцию от восстановления.
  Сообщать, что реконструировано и какие данные удалось проверить.
- Удалять только файлы в согласованной области запроса. Не восстанавливать
  намеренно удалённые материалы только потому, что они упомянуты в тексте.
- Не создавать коммиты и не публиковать документы без соответствующего запроса.
