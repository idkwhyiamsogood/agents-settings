# agents-settings

Переносимый набор правил, пользовательских skills и настроек Codex, Claude Code,
Cursor и VS Code. Репозиторий хранит намерения пользователя, а приложения создают
локальное состояние самостоятельно. Настройки не требуют конкретной ОС, оболочки,
имени пользователя, домашнего каталога, шрифта или интерпретатора.

Начните с [плана установки для ИИ-агента](docs/INSTALL.md).
[Карта связей](docs/ARCHITECTURE.md) объясняет новичку, что за что отвечает.
[Правила сопровождения](docs/MAINTENANCE.md) описывают обновление набора.

| Каталог | Назначение |
| --- | --- |
| `codex/` | Глобальные правила, тематические модули документов и минимальный config.toml |
| `claude/` | Постоянные правила Claude; пустой шаблон MCP |
| `skills/` | Единственный источник трёх пользовательских workflows с ресурсами |
| `cursor/user/`, `vscode/user/` | Переносимые настройки редакторов, сочетания клавиш и snippets |
| `docs/` | Установка, зависимости, связи и сопровождение |
| `scripts/install.py` | Планирование и копирование в явно заданный каталог |

Кэши, системные и встроенные skills, плагины с исполняемыми пакетами, аккаунты,
история, доверие проектам и разрешения команд не хранятся. Нет экспорта из
домашнего каталога и зависимости от символических ссылок. Плагины из
[необязательного списка](docs/plugins.json) устанавливаются средствами приложения.

Изменения относятся к этому репозиторию. Клонирование и подготовка набора
не меняют настройки уже установленных приложений.
