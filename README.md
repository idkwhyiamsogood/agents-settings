# agents-settings

Личный снимок настроек AI-инструментов: Codex, Claude Code, Cursor и VS Code.
Содержит правила, конфигурации MCP, skills и их ресурсы. Точное время экспорта,
список файлов и SHA-256 находятся в [manifest.json](manifest.json).

## Состав

| Каталог | Содержание |
| --- | --- |
| `codex/AGENTS.md` | Глобальные инструкции Codex. |
| `codex/document-rules/` | Общие модульные правила работы с документами. |
| `codex/config.toml` | Модель, параметры интерфейса, доверенные проекты, MCP figwright/drawio и разрешения инструментов. |
| `codex/rules/` | Сохранённые правила разрешения команд. |
| `codex/skills/` | Пользовательские Figma-skills и снимок системных skills с ресурсами. |
| `codex/plugins/` | Список пяти плагинов, их манифесты и доступные локально skills с ресурсами, включая шаблоны. |
| `claude/` | Глобальные инструкции, отдельная конфигурация MCP, библиотека skills и относительные ссылки активных skills. |
| `cursor/` | Skills, параметры запуска, пользовательские настройки редактора и сочетания клавиш. |
| `vscode/user/` | Настройки редактора, сочетания клавиш и имеющийся файл MCP. |
| `skill-links.json` | Относительные ссылки Claude skills в читаемом виде; сами ссылки также сохранены в Git. |
| `scripts/export_settings.py` | Повторный экспорт разрешённых конфигураций и проверка снимка. |

Системные и плагинные skills скопированы как снимок установленных ресурсов,
а не объявлены собственными разработками. Существующие лицензии и указания
авторов сохранены. Кэш плагинов не является полноценным установщиком плагинов
или заменой подключения к сервисам в приложении.

## Обновление

Из корня репозитория:

```bash
python3 scripts/export_settings.py
python3 scripts/export_settings.py --check
git diff --stat
git status --short
```

По умолчанию исходники читаются из домашнего каталога текущего пользователя.
Другой каталог можно указать через `--home /path/to/home`.
Экспорт использует явный список допустимых файлов. Произвольное содержимое
домашнего каталога не копируется. Ссылки skills сохраняются относительными.
JSON/JSONC нормализуются; поля распознаваемых секретов заменяются на
`<REDACTED>`. При обнаружении характерного токена, приватного ключа или URL
с паролем экспорт блокируется без вывода значения.

Перед commit/push всё равно просматривать изменения: автоматическая проверка
не гарантирует обнаружения всех видов секретов. Устаревшие файлы предыдущего
снимка скрипт сообщает для ручной проверки, а не удаляет автоматически.

## Восстановление на другом компьютере

Сначала сравнить файлы с настройками целевого компьютера и сохранить его
текущую конфигурацию. Автоматическое восстановление при клонировании не выполняется.

- `codex/AGENTS.md`, `codex/document-rules/`, пользовательские skills и нужные
  правила перенести в соответствующие места `~/.codex/` либо своего CODEX_HOME.
- `codex/config.toml` объединить с текущим конфигом. Абсолютные пути проектов,
  доверие к ним, версия модели и возможности MCP относятся к исходному компьютеру
  и могут требовать адаптации. Сохранённые разрешения команд проверять отдельно.
- Каталог `.system` управляется Codex: не заменять его целиком без необходимости.
  Снимок позволяет сверить версии и восстановить нужный ресурс отдельно.
- Плагины установить/подключить через поддерживаемый механизм приложения,
  используя `codex/plugins/installed.json` как инвентаризацию. Затем проверить,
  какие сохранённые skills нужны отдельно. Файлы кэша не восстанавливают OAuth
  или доступ к аккаунту.
- Файлы `claude/` сопоставить с `~/.claude/`. Из `claude/mcp.json` перенести
  только секцию `mcpServers` в соответствующую конфигурацию Claude Code,
  сохранив прочие локальные поля. Ссылки `claude/skills/` должны указывать
  на сохранённый рядом `skills-library/`.
- Для Cursor: `cursor/skills-cursor/` и прочие глобальные ресурсы сопоставить
  с `~/.cursor/`, а `cursor/user/` — с пользовательским каталогом приложения.
  `vscode/user/` аналогично сопоставить с каталогом User VS Code.
  Пути User различаются между ОС и вариантами установки.
- Проверить наличие Node.js/npx, Bun/bunx и остальных программ, на которые
  ссылаются конфигурации. Подключения к внешним сервисам авторизовать заново.

## Что исключено

В снимок не входят auth.json, OAuth-данные, сведения об аккаунтах, приватные
ключи, история переписки и команд, сессии, телеметрия, память в SQLite,
состояние редакторов и их workspaceStorage/globalStorage, резервные копии
учётных данных и исполняемые пакеты приложения. Для Claude из `.claude.json`
извлекается только `mcpServers`; сам файл в репозиторий не попадает.

Проектные исходники и инструкции из остальных репозиториев не собираются:
этот репозиторий хранит персональные настройки инструментов.
